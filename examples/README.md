# Private input contract

The bundled prospect dataset has been withdrawn. No prospect data or downloadable list replaces it.

`score_list.py` accepts an operator-supplied private input or stdin. An email field is required. Optional fields describe names, role, company, stage, industry, an evidenced signal and its date, and a LinkedIn URL. Missing optional evidence disables or flags the relevant check; it is never invented. Use only inputs you are authorized to process.

This describes software input fields, not a resource or a dataset. Do not create a sample CSV, publish private rows, or rewrap withdrawn rows in another format.
