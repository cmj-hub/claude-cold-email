# Banned patterns

Lines, openers, and closes the cold-email skill refuses to produce.
If a user explicitly asks for one, push back with the reason and offer
an alternative.

## Banned openers

| Banned | Why | Use instead |
|---|---|---|
| "Hope you're well" | Signals mass-blast template | Quote a signal verbatim |
| "Hope this finds you well" | Same | Same |
| "Hope your week is going well" | Same | Same |
| "I came across your LinkedIn" | Demographics, not signal | Quote a specific post / job change / launch |
| "I noticed you're a <role>" | Demographic | Quote what they did, not who they are |
| "I saw your company is growing" | Vague | Quote the specific signal (funding, hire, launch) |
| "Quick question" | Almost always not quick | State the actual question in the subject |
| "Hi there" | No personalization | First name |
| "Hey <name>!" with exclamation | Forced familiarity | "<Name> —" |

## Banned closes / CTAs

| Banned | Why | Use instead |
|---|---|---|
| "Let me know your thoughts" | Open-ended; no commitment | Binary, time-bound ask |
| "Happy to chat whenever" | No anchor | "15 min Thursday at 11am PT?" |
| "Interested?" | Single word; low effort | Specific binary ask |
| "Would love to learn more" | Vague | "Should I send the case study?" |
| "Let me know if..." | Conditional + open | Direct binary |

## Banned follow-up openers

| Banned | Why | Use instead |
|---|---|---|
| "Just bumping this" | Filler, no new value | Drop a new insight or case |
| "Following up on my last email" | Self-referential | Quote a new signal or peer outcome |
| "Did you get a chance to..." | Passive-aggressive | "If <pain> isn't on the roadmap, no worries — should I close the loop?" |
| "Just checking in" | Empty | Reframe the pain from a different angle |
| "Wanted to make sure you saw this" | Implies sender importance | Drop the most useful 1-liner you've got |

## Banned body patterns

| Banned | Why |
|---|---|
| Multi-paragraph value-prop monologues | Buyer doesn't read |
| Stacked questions ("Are you A? Or B? Or C?") | Forces choice paralysis |
| Bullet lists of features | Features are not signals |
| Phrases like "synergy", "leverage" (as verb), "circle back" | Tells the reader you're not paying attention |
| Sentences starting with "I" | Move recipient to subject of sentence |
| Generic personalization tokens that didn't merge ("Hi {{firstName}}") | Auto-rejects |

## Banned subject-line patterns

| Banned | Why |
|---|---|
| ALL CAPS subjects | Spam signal |
| Emojis (☀️ 🚀 🎯) | Deliverability hurt in B2B |
| "Re:" or "Fwd:" fakes | Deceptive subject line (CAN-SPAM); a spam signal to Gmail / Yahoo / Outlook filters |
| Clickbait ("You won't believe...", "This one trick...") | Will land in spam |
| "URGENT" / "ACT NOW" / "Limited time" | Spam triggers |
| Long subjects (>50 chars) | Truncated; lower open rate |

## How to push back on a user request

If the user pastes a draft with banned patterns, or asks for one
explicitly, respond:

```
That line / pattern is a banned pattern in the JMC framework because:
<one-sentence reason>. 

Here's the JMC-shaped alternative:
"<rewritten>"

Rationale: <one sentence>.
```

Don't lecture; rewrite once, move on.
